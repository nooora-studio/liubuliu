# 留不留

买了衣服，自己对着镜子看三天也看不出该不该留、搭得好不好看。把那件衣服发上来，让别人帮你投「留」或「退」，并写一句具体的搭配意见。

必需品通常不用问。纠结的是衣服。

## 可以做什么

- 看社区里快过退货期的纠结，先处理最紧急的
- 对一件衣服投「留下」或「退掉」
- 写具体意见：版型、颜色、和已有衣服是否重复、怎么搭
- 自己发一条：照片或示意图、价格、购买渠道、退货还剩几天
- 听完意见后，自己拍板「留下了」或「退掉了」

带「示意图」的帖子是示例。登录之后，你发的帖、投的票和写的意见记在 Vectoree 数据库里，跟账号走。

网页用邮箱注册。新用户要填邮箱里的 8 位验证码。微信小程序优先走微信登录：`wx.login` 的 code 交给服务端，服务端用这只小程序自己的 AppID / AppSecret 向微信换 openid，再在 Vectoree 里建成已验证账号。Vectoree 目前没有微信这个登录方式，也不能把微信小程序登录当成标准 OAuth 接进去。游客模式换不到 openid，所以要在环境变量里填 `WECHAT_APPID` 和 `WECHAT_SECRET` 之后，微信登录才会通。没填之前，小程序里可以改用邮箱。

服务端读取 `VECTOREE_API_KEY`。本地如果已经 `vectoree link`，会回退读取 `.vectoree/config.json`，这个目录不会进仓库。

## 本地运行

```bash
npm install
npm run dev
```

开发服务器地址是 [http://127.0.0.1:4261](http://127.0.0.1:4261)。

线上版本是 [https://liu-bu-liu.apps.grok.bot](https://liu-bu-liu.apps.grok.bot)。

## 微信小程序

`miniprogram` 是同一套「留不留」的微信小程序源码，不需要编译。用微信开发者工具打开本仓库（或直接打开 `miniprogram` 文件夹），AppID 选测试号 / 游客模式即可预览。

可以做的事和网页一样：按退货期看社区、投留下或退掉、写具体搭配意见、发自己的纠结、拍板留下了或退掉了。列表里的配图收成小图，详情里再放大一些。示意图用色块画衣服。

要把小程序提交到微信，需要你自己的小程序账号，并走微信审核。游客模式只能在开发者工具里预览，也完不成微信登录。
